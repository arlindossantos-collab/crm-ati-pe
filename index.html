O erro Missing or insufficient permissions ocorre porque as Regras de Segurança (Security Rules) do seu banco de dados Cloud Firestore estão bloqueando a gravação de novos documentos por usuários que não estão autenticados pelo Firebase Auth. Como a base de usuários passou a ser gerenciada internamente em uma coleção chamada usuarios, o Firebase considera a requisição como "pública/não autenticada" no momento do cadastro. 🔧 Solução: Atualizar as Regras do Firestore Acesse o Console do Firebase, selecione o projeto prgd-ati-pe e siga o passo a passo: No menu à esquerda, vá em Firestore Database. Clique na aba Regras (Rules) no topo da página. Substitua o conteúdo existente pelas regras abaixo: JavaScript rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Permite leitura e escrita na coleção de usuários match /usuarios/{email} { allow read, write: if true; } // Regra para as demais coleções do sistema match /{document=**} { allow read, write: if true; } } } Clique no botão Publicar (Publish) no canto superior direito. 📁 Arquivo do Projeto Ajustado Ícone do app HTML index HTML Após publicar essa regra no painel do Firebase, tente salvar o usuário novamente pelo formulário e a operação será concluída com sucesso.
