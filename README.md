# PRGD - Plataforma de Relacionamento do Governo Digital (ATI-PE)

Aplicação otimizada para sincronização em tempo real com o Firestore Cloud, compatível com qualquer navegador moderno (Chrome, Firefox, Safari, Edge).

## Configuração Inicial
1. Certifique-se de habilitar o provedor de E-mail/Senha no console do Firebase Authentication.
2. Publique as regras de segurança (`firestore.rules`) no painel do Firestore.
3. Acesse a aplicação e utilize as credenciais de Administrador (`arlindo.santos@ati.pe.gov.br` / `123`) para gerenciar e sincronizar registros instantaneamente.
